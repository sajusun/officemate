2. DETAILED STORE DESCRIPTION (COPY & PASTE READY)
--------------------------------------------------------------------------------
💼 OfficeMate for Edge: The Executive Productivity Copilot for Microsoft 365

Reclaim 10+ hours every week from repetitive Outlook email replies, messy meeting notes, and cluttered browser tabs.

OfficeMate brings an intelligent productivity sidebar and in-page copilot directly into Microsoft Edge, engineered specifically for professionals, managers, and remote workers who live inside Outlook Web, Microsoft Teams, and cloud web apps.

🔒 100% CLIENT-SIDE PRIVACY ARCHITECTURE:
Confidential corporate communications, emails, and client research URLs NEVER leave your computer. All email draft generation, workspace tab stashing, and note taking run locally inside your browser sandbox. Zero telemetry. Zero remote databases.

🌟 CORE CAPABILITIES:

1. ✉️ 1-Click Executive Outlook Email Replies:
• Injects a floating Smart Reply button directly into Outlook Web.
• Select from curated corporate tones: Polite Pushback, Executive Status, Formal Alignment, Meeting Reschedule, or Friendly Follow-up.
• Automatically personalizes sign-offs with your name, job title, and company.

2. 🗂️ Project Workspace Tab Stasher (Ctrl + Shift + U):
• Working on multiple client projects? Stash 30+ open tabs into named workspaces with one shortcut.
• Frees up system RAM and lets you restore entire project sessions instantly without losing context.

3. 📝 Teams Meeting Notes & Action-Item Extractor:
• Highlight messy meeting chat threads or transcript segments and instantly distill them into structured action items with assigned owners and deadlines.

4. ⚡ Conflict-Free Global Shortcuts:
• Alt + Shift + C : Toggle floating Copilot Sidebar on any active tab.
• Ctrl + Shift + U : Quick-stash current window tabs into a new workspace.

5. 🔑 Offline Heuristics + Optional BYOK:
• Works 100% offline with zero subscription fees using built-in corporate template heuristics.
• Advanced users can optionally connect their personal OpenAI (GPT-4o) or Google Gemini API key for dynamic contextual generation.

⭐ FREE VS PRO:
• Free Community Edition: 3 AI drafts/day, 1 saved workspace, full sidebar.
• Pro Lifetime License ($8.99): Unlimited daily drafts, unlimited workspaces, custom signatures, 3-device roaming activation, and lifetime updates.

4. PERMISSIONS JUSTIFICATION (MICROSOFT EDGE AUDIT)
--------------------------------------------------------------------------------
• storage:
  Used to store user preferences (sender name, job title, signature, AI provider selection) and save stashed workspace tab URLs in local browser storage (chrome.storage.local).

• tabs:
  Required by the Workspace Tab Stasher to read currently open tab URLs and titles when the user clicks "Stash Current Tabs" and restore them when reopening a workspace.

• activeTab:
  Used to summon and toggle the floating Copilot Sidebar overlay on the user's active tab upon pressing the keyboard shortcut (Alt+Shift+C).

• scripting:
  Required to programmatically inject the isolated Copilot sidebar component and Outlook Smart Reply button into the active tab's DOM.

• contextMenus:
  Used to provide right-click context menu shortcuts ("Save selection as Meeting Note", "Open OfficeMate Sidebar").

• host_permissions ("https://api.gumroad.com/*", "https://api.openai.com/*", "https://generativelanguage.googleapis.com/*"):
  - https://api.gumroad.com/* : Used solely to verify user license keys against Gumroad's license validation API.
  - https://api.openai.com/* & https://generativelanguage.googleapis.com/* : Used strictly when the user optionally enables the BYOK (Bring-Your-Own-Key) AI provider and enters their personal API key.
